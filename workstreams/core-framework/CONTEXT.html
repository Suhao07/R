组合层角色和证据术语。

active-instance

术语

primary framework
由项目维护、承接新实现和正式证据的主代码框架；当前仅 Urban-Nav-SR 与 ms-swift。
integration control
组合 exact commits、contracts、runs 和 release gates 的项目，不复制 owner 仓实现。
reference repository
用于方法研究、比较或采用的上游代码/数据仓；默认只读，不承担项目 release。
promotion
把参考方法的一部分纳入主框架前进行的显式决策，包含来源 commit、license、target owner、适配和测试。
policy profile
repo matrix 中将共享政策、领域规则和机器配置绑定到一个仓库角色的声明。
doctor pass
组合结构和 saved/live snapshot 一致；不代表主仓代码、benchmark 或 release gate 全部通过。
